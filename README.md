# Echoic
This is an app made in swift meant to help people better recall auditory memories

A lot of emphasis is put on visual memories, but not as much on sounds, even when a sound can remind you of so much.

This was created with Swift and AVAudio and a challenge I had was properly implementing the save feature however I was able to figure this out!
